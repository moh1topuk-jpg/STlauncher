# Список изменений

Здесь перечислено, что меняется от версии к версии. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

Текст каждой версии попадает в описание релиза на GitHub автоматически, поэтому
пишется для игрока: что изменилось для него, а не какие файлы поправлены.

## [Не выпущено]

### Добавлено
- Заставка при запуске: искры слетаются в кольцо вокруг логотипа, пока лаунчер готовит
  сборку, вспышка, когда всё готово, и экран проявляется, а логотип уплывает на своё место
  в панели слева. Длится около двух секунд, при долгой загрузке кольцо кружит дольше.

### Изменено
- Лаунчер запускается заметно быстрее: выбранная сборка появляется на экране сразу, до
  обращений в сеть; установленные версии Java ищутся в фоне и запоминаются, а не
  опрашиваются при каждом старте; список версий игры берётся из кэша и обновляется не
  чаще раза в 12 часов. В лог лаунчера пишется, сколько заняла каждая ступень запуска.

## [0.5.0] — 2026-09-24

### Добавлено
- Оптимизация одной кнопкой в настройках: «Слабый ПК», «Сбалансированно», «Максимум».
  Выставляет графику в игре и память под этот компьютер; в свою сборку на Fabric ещё
  добавляет моды оптимизации из сборки сервера. Управление и звук не трогает.
- Вкладка «Скриншоты» у сборки: всё, что игра сохранила по F2, новые сверху. Клик открывает
  во весь экран, кнопка копирует файл, чтобы вставить в чат, удаление спрашивает один раз.
- Настройки игры переносятся между сборками: новая сборка берёт управление, звук и графику
  из текущей, а любой сборке их можно скопировать из другой на вкладке «Настройки сборки».
- Обновления ресурспаков и шейдеров, как у модов: кнопка «Проверить обновления» на их
  вкладках сверяет файлы с Modrinth и показывает, у каких есть новее. Ставится по кнопке,
  порядок паков и активный шейдер при этом сохраняются. Паки из каталога сервера обновляет
  сервер.
- Проверка сборки до запуска. Лаунчер читает, что моды говорят о себе, и сразу показывает,
  что помешает игре стартовать: нет нужного мода, один мод стоит дважды, мод не для этого
  загрузчика или не для этой версии игры. У каждой проблемы кнопка: включить, выключить
  лишний или найти недостающее в каталоге. Раньше то же самое лаунчер объяснял уже после
  падения.
- «Безопасный запуск»: игра стартует только с модами сервера, ваши моды на этот раз
  выключаются и возвращаются после выхода. Если лаунчер закрылся вместе с игрой, вернутся
  при следующем запуске.
- Проверка сети в настройках: отвечают ли GitHub, зеркало, Modrinth, Mojang, Adoptium и
  сервер, с временем ответа и кнопкой «Скопировать отчёт».
- Поиск по списку модов сборки и кнопки «Выключить свои» / «Включить свои»: моды каталога
  сервера не трогаются.
- Светлая тема и выбор цвета акцента в настройках: семь цветов, применяются сразу, без
  перезапуска. Кнопка «Играть», переключатели, выделение и подсветка перекрашиваются
  вместе.
- Лаунчер задвигался: кнопки плавно меняют цвет и слегка проседают при нажатии, большая
  кнопка «Играть» светится под курсором, значки в левой панели приподнимаются, а разделы,
  вкладки и карточки появляются с коротким выездом, а не рывком.

### Изменено
- Подготовка к Linux и macOS, для Windows ничего не меняется: Java ищется и
  распаковывается по правилам каждой системы, сборки других лаунчеров ищутся по их путям
  на Linux и macOS. Сборка для Linux собирается в CI как черновик и не публикуется.

## [0.4.1] — 2026-09-23

### Добавлено

## [0.4.0] — 2026-09-23

### Добавлено
- У сборки появились вкладки «Ресурспаки» и «Шейдеры» — раньше паки лежали в общем списке
  с модами. Ресурспаки можно включать, выключать и менять местами прямо в лаунчере:
  верхний в списке перекрывает остальные, как в меню игры. Порядок записывается в
  options.txt, и игра применяет его при запуске. У каждого пака видно картинку и описание
  из самого архива, размер, откуда он взялся и подходит ли он к версии игры в сборке.
- Шейдеры выбираются в лаунчере: один активный или «Без шейдеров». Выбор записывается в
  настройки Iris (на Forge — Oculus), и игра стартует уже с ним. Если в сборке нет ни Iris,
  ни Oculus, лаунчер об этом скажет и предложит найти нужный мод в каталоге.

### Изменено
- Установщик по ссылке для игроков теперь один на несколько версий, а не новый на каждый
  релиз: Windows копит доверие к конкретному файлу, и предупреждение SmartScreen будет
  появляться реже, чем чаще этот файл скачивают. После установки лаунчер сам обновляется
  до последней версии при первом запуске.
- Пока игра запущена, паки и шейдеры менять нельзя — игра перезаписала бы настройки при
  выходе. Кнопки на это время отключаются.

## [0.3.4] — 2026-09-22

### Изменено
- Анонимный пинг статистики теперь уходит после первой проверки обновлений и сообщает,
  чем она закончилась (например, «через зеркало» или «GitHub заблокирован, зеркало не
  ответило»). Владелец видит сводку за неделю в разделе «Для разработчиков» и понимает,
  что именно не работает у игроков, без их логов.

## [0.3.3] — 2026-09-22

### Исправлено
- Запуск стал заметно быстрее: лаунчер больше не пересчитывает хэши всех файлов игры
  перед каждым стартом (тысячи ассетов и библиотек). Файл проверяется один раз, дальше
  сверяются только размер и дата изменения; всё, что изменилось, проверяется заново.
  Галочка «Принудительно обновить игру» по-прежнему перепроверяет всё целиком.
- Обновления для тех, у кого заблокирован GitHub. Раньше лаунчер шёл по источникам
  по очереди и мог ждать заблокированный адрес до пяти минут; проверка начиналась с
  GitHub, а зеркало узнавалось только из каталога. Теперь каталог запрашивается с GitHub
  и с зеркала одновременно, у каждого адреса 15 секунд; проверка обновлений идёт по
  списку: зеркала из каталога, затем зеркало, зашитое в лаунчер, потом GitHub, у каждого
  20 секунд; скачивание идёт через тот источник, что ответил. Кнопка «Скачать вручную»
  ведёт на установщик через зеркало, а не на GitHub. В каталог можно добавить второе
  зеркало (`updateFeedUrls`) без выпуска новой версии.
- Лог лаунчера теперь пишется в файл (`logs/launcher.log`), кнопка «Открыть лог-файл»
  есть в консоли и в разделе «Для разработчиков». По каждому источнику обновлений в нём
  видно, чем он ответил.
- Режим «Авто» у скинов показывал Стива для ников, которые есть в TLauncher: в кэше
  оставался Стив от зеркала, сохранённый прежней версией, и «Авто» ему доверял. Теперь
  из кэша берутся только скины от Mojang, TLauncher и ely.by, а ответы зеркал не
  сохраняются вовсе.

### Изменено
- Поля «Каталог контента», «Адрес сборщика статистики» и число пользователей лаунчера
  в разделе «Для разработчиков» видны только владельцу сервера: нужен `"OwnerTools": true`
  в `settings.json`. Игрокам эти поля не нужны.

## [0.3.2] — 2026-09-22

### Добавлено
- После обновления на главном экране появляется карточка «Что нового» со списком
  изменений этой версии. Открыть снова: Настройки → «Что нового в этой версии».
- Если игра упала, лаунчер читает её лог и называет причину по-русски: «моду X нужен
  Fabric API», «не хватило памяти», «нужна Java 21», «мод для другой версии», «два
  одинаковых мода», «видеодрайвер не открыл окно», «файл игры повреждён», «диск заполнен».
  Рядом — кнопка с исправлением, где оно в один клик (выделить память, вернуть
  автоматическую Java, перекачать файлы, найти недостающий мод в каталоге), и кнопка
  «Копировать отчёт»: версия лаунчера, сборка, список модов и нужные строки лога — можно
  сразу вставить в чат поддержки.
- Во вкладке «Моды» появилась кнопка «Проверить обновления»: лаунчер сверяет моды с
  Modrinth по хэшу файла и помечает те, у которых есть новая версия под вашу сборку.
  Сам ничего не ставит — обновить можно по одному или все сразу, решение за вами. Моды
  из каталога сервера не проверяются: их версии задаёт сервер.
- Бэкапы теперь можно восстановить прямо из лаунчера. В настройках виден список
  бэкапов: сборка, дата, размер, сколько внутри миров и модов. У каждого — «Только миры»,
  «Всю сборку» или «Как новую сборку». Перед восстановлением в существующую сборку её
  текущее состояние сохраняется отдельным бэкапом. В бэкап теперь попадает и описание
  сборки (версия, загрузчик, память), так что удалённую сборку можно поднять из бэкапа
  целиком. Кнопка удаления бэкапа тоже здесь.
- Первый запуск начинается с короткого знакомства: ник (с 3D-моделью скина), память
  для игры с рекомендацией под этот компьютер, перенос сборок из других лаунчеров, и
  готово. Экраны сменяются анимацией, любой шаг и всё знакомство целиком можно
  пропустить. Тем, у кого лаунчер уже стоял, оно не показывается.
- Ползунок памяти в настройках больше не сбрасывает значение при первом показе.
- Статус в Discord: пока игра запущена, у вас в профиле видно «Играет на Showtime»,
  сборку и версию, с кнопкой на сайт сервера. Отключается в настройках («Лаунчер»).
  Включается владельцем сервера через каталог (поле `discordAppId`).
- В каталоге «Добавить моды» появились ресурспаки и шейдеры — переключатель над поиском.
  Ставятся в свои папки, у каждого вида свои категории; ресурспаки доступны и для
  ванильной сборки. Установленные видны во вкладке «Моды» с пометкой; включаются, как
  обычно, внутри игры.
- Пока игра запущена, лаунчер сворачивается в трей вместо панели задач: значок рядом с
  часами, по клику окно возвращается, в меню — «Показать» и «Выйти». Настройка «После
  запуска» теперь так и называется: «Свернуть в трей».
- Папку данных лаунчера (сборки, миры, версии, Java) можно перенести на другой диск:
  Настройки → «Лаунчер» → «Перенести…». Всё копируется целиком, старая папка очищается
  только после удачного копирования, затем лаунчер перезапускается сам.
- Когда владелец сервера меняет рекомендуемую сборку в каталоге, на главном экране
  появляется карточка «обновление из каталога»: что добавлено, что убрано, что обновлено,
  сменилась ли версия игры или загрузчика. Раньше файлы приходили молча.
- Анонимная статистика запусков: раз за запуск лаунчер сообщает сборщику случайный
  идентификатор установки, версию, язык и ОС — чтобы владелец видел, сколько людей
  пользуются лаунчером. Ник и файлы не передаются; отключается в настройках
  («Лаунчер»). Цифры видны в разделе «Для разработчиков».
- Под 3D-моделью игрока — переключатель системы скинов: «Авто», Mojang, TLauncher,
  ely.by. Если ник есть в нескольких системах с разными скинами, можно посмотреть каждый
  и оставить нужный; выбор запоминается. «Авто» берёт первый найденный в порядке
  Mojang → TLauncher → ely.by.

### Исправлено
- Скины игроков без аккаунта Mojang теперь берутся из TLauncher и ely.by — там, где игроки
  их ставили. Раньше лаунчер показывал таким игрокам Стива: зеркало mc-heads отвечает
  Стивом на любой неизвестный ник, и лаунчер принимал его за настоящий скин. Под 3D-моделью
  теперь написано, откуда взят скин или почему он не найден.
- Каталог модов в небольшом окне: карточки теряли название, категории занимали шесть
  строк, пустая панель справа отбирала треть места. Теперь число колонок подстраивается
  под ширину, категории — в одной прокручиваемой строке, панель появляется только когда
  открыт мод.

## [0.3.1] — 2026-09-22

### Добавлено
- Каталог модов переделан в витрину: категории — кнопками-чипами, моды — карточками с автором,
  числом загрузок и метками, у установленных — «в сборке». Справа постоянная панель
  выбранного мода вместо всплывающего окна: описание, галерея, версия под вашу сборку,
  что мод требует и с чем сочетается, кнопки «Добавить в сборку», «Убрать из сборки»,
  «Другая версия».
- Моды ставятся вместе со своими зависимостями: если моду нужен Fabric API, он
  добавится сам — раньше игра просто падала при запуске.
- Галочка «Скрыть уже установленные» в каталоге.
- Живой фон на главном экране: неяркие искры медленно плывут вверх и слегка отклоняются
  от курсора. Отключается в настройках («Лаунчер»).
- Под лицом игрока на главном экране подсказка, что по нему можно нажать.

### Исправлено
- После запуска игры с главного экрана пропадали название сборки, версия и загрузчик:
  обновление строки в списке сборок сбрасывало выбранную сборку.
- Переключение на English ломало интерфейс: в английском словаре была продублирована
  строка, и весь словарь не загружался.
- Надпись «Поиск на Modrinth…» в строке состояния оставалась навсегда. Теперь она
  снимается по окончании поиска, а любое сообщение в строке состояния само исчезает
  через 12 секунд, если ничего не выполняется.

## [0.3.0] — 2026-09-22

### Добавлено
- Скин игрока в 3D: нажмите на лицо на главном экране или в панели слева — модель с
  вашим скином поворачивается сама, её можно покрутить мышью. Различаются широкая и
  тонкая («Алекс») модели, старые скины 64×32 тоже поддерживаются.
- На главном экране: состояние сборки (сверена ли с каталогом, когда последний запуск)
  и сколько игроков сейчас на сервере — одной строкой, со ссылкой в раздел.
- В разделе «Сборки» появилась кнопка «Играть» — не нужно возвращаться на главный экран.
- Адрес сервера копируется кнопкой рядом с ним.
- Лаунчер сам находит сборки других лаунчеров при запуске и предлагает перенести их —
  карточкой на главном экране и в «Сборках», с кнопкой «Перенести». Предложение можно
  закрыть навсегда. Кнопка «Найти сборки других лаунчеров» теперь всегда видна под
  списком сборок, а не только в меню «+ Добавить».

### Изменено
- Новое оформление. Заголовки шрифтом Manrope, единая шкала размеров, карточки без
  рамок, векторные иконки вместо текстовых символов.
- Навигация — узкая панель слева с иконками; контенту достаётся больше места. Внизу
  панели — версия лаунчера (краснеет, когда есть обновление) и ваш аватар.
- Главный экран стал витриной: название сборки крупно, большая кнопка «Играть», выбор
  сборки рядом с ней. Ник показан текстом и меняется по кнопке.
- Раздел «Сервер»: шапка-баннер с логотипом и статусом, плитки метрик (онлайн сейчас, за
  неделю, рекорд, аптайм, место в Top-Minecrafter), график — плавная область с сеткой,
  осью и подсказкой при наведении; сайт, Telegram и Discord — карточками.
- Сборки: моды в две колонки, у выбранной сборки цветная полоска, вкладка «Каталог
  модов» переименована в «Добавить моды».
- Настройки: оглавление слева, разделы «Игра», «Лаунчер», «Бэкапы», «Для
  разработчиков». Память — ползунок с рекомендуемым значением для этого компьютера.
  Разрешение окна — галочка «Как в игре» вместо «0 × 0».
- Строка состояния показывает прогресс только пока что-то загружается.

### Исправлено
- Скины иногда не загружались: запрос к одному сайту мог висеть до пяти минут, а при
  сбое запасного не было. Теперь сначала спрашивается Mojang, затем два зеркала, у
  каждого короткий таймаут; последний удачный скин хранится на диске, а Стив по
  умолчанию встроен в лаунчер.
- Широкая или тонкая модель берётся из профиля Mojang, а не угадывается по текстуре:
  скины широкой модели, нарисованные на тонком шаблоне, больше не выглядят кривыми.
- Импорт сборок из других лаунчеров работал только для TLauncher. Теперь находятся и
  разбираются сборки Prism Launcher, PolyMC, MultiMC, CurseForge, Modrinth App (включая
  новые версии без файла профиля), GDLauncher, ATLauncher, FTB App, Technic и XMCL —
  в том числе переносные установки на рабочем столе, в загрузках и в корне диска, а также
  папка сборок, перенесённая в настройках Prism.
- Профили официального лаунчера и TLauncher с собственной папкой игры находятся как
  отдельные сборки.
- Сборка, у которой лаунчер не оставил описания, больше не пропадает: версия и
  загрузчик определяются по модам, а если модов нет — выбираются после импорта.
- Версии игры с новой нумерацией («26.2») определяются правильно.

## [0.2.9] — 2026-09-18

### Добавлено
- Раздел «Сборки» переделан. Слева — только список сборок, поиск и одна кнопка
  «+ Добавить»: новая сборка, сборка из каталога, импорт из других лаунчеров, копия.
- У каждой сборки видно, откуда она: из каталога, подключена из папки другого лаунчера
  или импортирована.
- Новая вкладка «Моды»: переключатель у каждого мода, размер файла, выключенные моды
  приглушены, кнопка «Папка модов».
- Если игра закрылась с ошибкой, лаунчер показывает код ошибки и кнопку «Открыть лог».

### Изменено
- «Закрыть лаунчер после запуска» теперь прячет окно, а не закрывает программу сразу.
  Лаунчер дописывает лог и завершается, когда игра закрыта; если игра упала — окно
  возвращается и объясняет, что случилось. Раньше лаунчер просто исчезал, и ошибку было
  не увидеть.

### Исправлено
- Сборки из TLauncher не запускались: «игра завершена, код 1». Лаунчер не понимал формат
  профилей TLauncher и запускал Java без библиотек.
- Выбор сборки в старом списке «Рекомендуемые сборки» применял её к открытой сборке и мог
  перезаписать импортированную.
- У импортированных сборок снова показывается число модов.

## [0.2.8] — 2026-09-18

### Изменено
- Проверка обновлений запускается сразу при старте, а её результат виден под кнопкой
  обновления: «проверка…», «актуальная версия» или «не удалось проверить».

### Исправлено
- Импорт сборок TLauncher с отдельной папкой для версии: моды, миры и настройки берутся
  из папки самой версии, а не из общего `.minecraft`.
- При копировании сборки больше не копируются файлы чужого лаунчера: `.exe`, его
  настройки, кэши и файлы входа в аккаунт.
- Импортированная сборка запускается своим профилем, а версия игры и загрузчика
  определяется по нему — каталог модов снова работает для таких сборок.
- Выбор сборки больше не стирает её версию.
