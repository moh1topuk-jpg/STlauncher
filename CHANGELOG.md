# Список изменений

Здесь перечислено, что меняется от версии к версии. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

Текст каждой версии попадает в описание релиза на GitHub автоматически, поэтому
пишется для игрока: что изменилось для него, а не какие файлы поправлены.

## [Не выпущено]

## [0.2.9] — 2026-09-18

### Добавлено
- Раздел «Сборки» переделан. Слева — только список сборок, поиск и одна кнопка
  «+ Добавить»: новая сборка, сборка из каталога, импорт из других лаунчеров, копия.
- У каждой сборки видно, откуда она: из каталога, подключена из папки другого лаунчера
  или импортирована.
- Новая вкладка «Моды»: переключатель у каждого мода, размер файла, выключенные моды
  приглушены, кнопка «Папка модов».
- Если игра закрылась с ошибкой, лаунчер показывает код ошибки и кнопку «Открыть лог».

### Изменено
- «Закрыть лаунчер после запуска» теперь прячет окно, а не закрывает программу сразу.
  Лаунчер дописывает лог и завершается, когда игра закрыта; если игра упала — окно
  возвращается и объясняет, что случилось. Раньше лаунчер просто исчезал, и ошибку было
  не увидеть.

### Исправлено
- Сборки из TLauncher не запускались: «игра завершена, код 1». Лаунчер не понимал формат
  профилей TLauncher и запускал Java без библиотек.
- Выбор сборки в старом списке «Рекомендуемые сборки» применял её к открытой сборке и мог
  перезаписать импортированную.
- У импортированных сборок снова показывается число модов.

## [0.2.8] — 2026-09-18

### Изменено
- Проверка обновлений запускается сразу при старте, а её результат виден под кнопкой
  обновления: «проверка…», «актуальная версия» или «не удалось проверить».

### Исправлено
- Импорт сборок TLauncher с отдельной папкой для версии: моды, миры и настройки берутся
  из папки самой версии, а не из общего `.minecraft`.
- При копировании сборки больше не копируются файлы чужого лаунчера: `.exe`, его
  настройки, кэши и файлы входа в аккаунт.
- Импортированная сборка запускается своим профилем, а версия игры и загрузчика
  определяется по нему — каталог модов снова работает для таких сборок.
- Выбор сборки больше не стирает её версию.

## [0.2.7] — 2026-09-18

### Добавлено
- Импорт сборок из других лаунчеров: `.minecraft` (официальный лаунчер, TLauncher),
  Prism, MultiMC, CurseForge, Modrinth App, GDLauncher, ATLauncher или любая папка.
  На выбор — подключить на месте или скопировать к себе; объём копии виден заранее.
- Если GitHub недоступен, каталог и обновления приходят через зеркало.

### Изменено
- Лаунчер больше не дописывает свой сервер в список серверов чужих лаунчеров.

## [0.2.6] — 2026-09-18

### Добавлено
- Кнопка «Проверить обновления» / «Обновить до версии…» всегда видна в боковой панели.
- Понятная ошибка, если проверке обновлений мешает провайдер или антивирус, и кнопка
  «Скачать вручную».

### Изменено
- Главный экран стал нейтральным: сервер и его статистика вынесены в раздел «Сервер»,
  «Играть на сервере» — дополнительная кнопка. Место в рейтинге подписано: Top-Minecrafter.
- Моды рекомендуемой сборки при запуске сверяются, а не скачиваются заново: докачиваются
  только недостающие. Выключенный мод остаётся выключенным.

### Исправлено
- Правильные окончания: «1 мод», «2 мода», «5 модов».
- Профили версий, сохранённые другими лаунчерами, больше не ломают разбор.

## [0.2.5] — 2026-09-18

### Добавлено
- Рекомендуемая сборка создаётся и обновляется сама при каждом запуске — играть можно
  одной кнопкой, в раздел «Сборки» заходить не нужно.
- Мониторинг онлайна переписан: 24 часа и 7 дней, средний онлайн, рекорд, аптайм, место
  в рейтинге. История собирается круглосуточно, а не только пока открыт лаунчер.
- Вместо общего ника «Player» при первом запуске придумывается свой, есть кнопка «↻».

### Исправлено
- Защита от повреждённых файлов версий и от зацикленных профилей загрузчиков.

## [0.2.4] — 2026-09-17

### Добавлено
- Кнопка, которая добавляет рекомендуемую сборку из каталога одним нажатием.

## [0.2.3] — 2026-09-17

### Исправлено
- Бэкап больше не подвешивает окно, а прерванный бэкап не выдаётся за целый.
- Лог игры пишется без лишней нагрузки.

## [0.2.2] — 2026-09-17

Первый публичный релиз.

### Добавлено
- Офлайн-вход по нику, все версии Minecraft, автоматическая загрузка Java.
- Fabric, Quilt, Forge и NeoForge.
- Сборки: у каждой свои моды, миры и настройки.
- Каталог модов Modrinth прямо в лаунчере, импорт модпаков `.mrpack`.
- Раздел сервера со статусом и ссылками сообщества.
- Бэкапы миров по событиям: раз в сутки, перед изменением модов, перед запуском.
- Автообновление с уведомлением и установкой одной кнопкой.
