# CurseForge как второй источник модов

Часть модов есть только на CurseForge. Его API требует ключ в каждом запросе, а ключ
нельзя положить в лаунчер с открытым кодом: его вытащат за минуту. Поэтому лаунчер
спрашивает не CurseForge, а зеркало (тот же воркер `showtime-updates`), а зеркало
добавляет ключ и пересылает запрос дальше.

Пока ключа нет, игрок ничего не видит: лаунчер спрашивает `GET /cf/ping`, получает 503
и не показывает CurseForge вообще. Ключ добавлен, воркер обновлён — `/cf/ping` отвечает
200, и источник появляется у всех после перезапуска лаунчера. Выпускать версию для этого
не нужно.

Адрес: лаунчер использует `https://showtime-updates.moh1topuk.workers.dev/cf`, а
`curseForgeUrl` в `catalog.json` его переопределяет. Пустой `curseForgeUrl` выключает
CurseForge у всех без выпуска версии.

## Настройка, один раз

1. Получить ключ: войти на [console.curseforge.com](https://console.curseforge.com/),
   раздел *API keys*. Если ключ там не выдаётся сразу, как подать заявку, описано в
   начале [docs.curseforge.com/rest-api](https://docs.curseforge.com/rest-api/); в заявке
   указать, что это лаунчер Minecraft с открытым кодом и что ключ хранится на сервере, а
   не в программе. Ключ выглядит как длинная строка, начинающаяся с `$2a$10$`.
2. Cloudflare → воркер `showtime-updates` → *Settings* → *Variables and Secrets* →
   добавить **секрет** `CF_API_KEY` со значением ключа. Именно секрет, не переменную:
   значение секрета не видно ни в панели, ни в коде.
3. *Edit code* → вставить свежий [`workers/updates/worker.js`](../workers/updates/worker.js) → *Deploy*.

Проверка:

- `curl https://showtime-updates.moh1topuk.workers.dev/cf/ping` отвечает `ok`.
  `curseforge is not set up on this mirror` значит, что секрета нет;
  `curseforge refused the key (HTTP 403)` значит, что ключ неверный или ещё не одобрен.
- `curl -H "X-STlauncher: test" "https://showtime-updates.moh1topuk.workers.dev/cf/v1/mods/search?classId=6&gameVersion=1.21.1&searchFilter=jei"`
  отдаёт JSON со списком модов.

## Что зеркало пропускает

Только то, что нужно лаунчеру, и только Minecraft (игра 432):

| Запрос | Зачем |
| --- | --- |
| `GET /cf/ping` | есть ли рабочий ключ |
| `GET /cf/v1/mods/search` | поиск: моды (класс 6), ресурспаки (12), шейдеры (6552) |
| `GET /cf/v1/categories` | категории для этих трёх классов |
| `GET /cf/v1/mods/{id}` и `/description` | страница мода |
| `GET /cf/v1/mods/{id}/files` и `/files/{fileId}` | файлы под версию игры и загрузчик |
| `GET /cf/v1/mods/{id}/files/{fileId}/download-url` | адрес файла на CDN |
| `POST /cf/v1/fingerprints/432` | узнать моды, которые уже лежат в папке |

Всё остальное получает 404. Параметры запроса собираются заново из разрешённого списка,
`gameId` подставляет само зеркало, а для запросов по номеру мода зеркало сначала
проверяет, что это мод Minecraft. Ответы хранятся на стороне Cloudflare пять минут,
так что страница поиска тратит один запрос по ключу на всех игроков, а не по одному
на каждого.

## Что стоит знать

- Сами файлы лаунчер качает не через зеркало, а напрямую с CDN CurseForge
  (`edge.forgecdn.net`, `mediafilez.forgecdn.net`) и сверяет SHA-1 с тем, что дал API.
  С любого другого адреса файл не скачивается.
- Автор мода может запретить скачивание сторонними программами. Тогда адреса у файла
  нет, и лаунчер предлагает открыть страницу мода в браузере и положить файл в сборку
  руками. Это не ошибка и не чинится ключом.
- Запросы без заголовка `X-STlauncher` зеркало отклоняет (403). Это не защита, а
  отсев случайных ботов. Чтобы ключом не пользовались чужие программы, в Cloudflare →
  *Security* → *WAF* → *Rate limiting rules* можно ограничить адреса, начинающиеся с
  `/cf/`, до, скажем, 120 запросов в минуту с одного адреса. На бесплатном плане такое
  правило одно: если оно уже занято под `/report`, его можно сделать общим для обоих путей.
- Убрать CurseForge у всех: удалить секрет `CF_API_KEY` (или поставить пустой
  `curseForgeUrl` в каталоге). Лаунчер перестанет его показывать после перезапуска;
  уже установленные моды остаются в сборках.
- Экспорт в `.mrpack`: формат разрешает ссылки только на Modrinth и GitHub, поэтому
  моды с CurseForge, которых нет на Modrinth, едут внутри файла. Код сборки (`STB1.…`)
  — свой формат лаунчера, в нём ссылки на CDN CurseForge разрешены.
