# Отчёты от игроков в Telegram

«Отправить админу» на карточке о падении и в Настройки → Дополнительно собирает тот же
zip, что и «Собрать отчёт», показывает игроку, что в нём, и после нажатия отправляет
его на зеркало. Зеркало ничего не хранит: файл сразу уходит ботом в Telegram владельца
как документ с подписью «ник · версия · комментарий игрока».

Кнопка появляется только когда адрес есть и отвечает на GET кодом 200 (старое зеркало
отвечает 405, и кнопки нет, пока воркер не обновлён). Адрес: лаунчер использует
`https://showtime-updates.moh1topuk.workers.dev/report`, а `reportUrl` в `catalog.json`
его переопределяет. Пустой `reportUrl` в каталоге кнопку убирает без выпуска версии.

## Настройка, один раз

1. В Telegram написать [@BotFather](https://t.me/BotFather): `/newbot`, имя, получить токен.
2. Написать своему боту любое сообщение, затем открыть
   `https://api.telegram.org/bot<токен>/getUpdates` и взять `chat.id` из ответа. Для
   группы: добавить бота в группу, написать в ней, взять отрицательный `chat.id`.
3. Cloudflare → воркер `showtime-updates` → *Settings* → *Variables and Secrets*:
   секрет `TG_BOT_TOKEN` с токеном, секрет `TG_CHAT_ID` с id чата.
4. *Edit code* → вставить свежий [`workers/updates/worker.js`](../workers/updates/worker.js) → *Deploy*.

Проверка: `curl -X POST -H "X-STlauncher: test" -F nick=test -F version=test -F comment=hi -F file=@любой.zip https://showtime-updates.moh1topuk.workers.dev/report`
должен ответить `delivered`, а в Telegram появится файл.

## Что стоит знать

- Лимит 8 МБ на отчёт, обычный отчёт весит 1–3 МБ (хвосты логов по 2 МБ).
- Адрес открытый. Чтобы никто не заваливал чат, в Cloudflare → *Security* → *WAF* →
  *Rate limiting rules* можно ограничить `POST /report` до, скажем, 5 запросов в 10
  минут с одного адреса. На бесплатном плане одно такое правило доступно.
- Если секреты не заданы, зеркало отвечает 503, а лаунчер пишет игроку, что отправить не
  вышло, и предлагает «Собрать отчёт» и переслать файл руками.
